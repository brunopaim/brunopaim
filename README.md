## About me

I am a software engineer with professional experience since 2021, focused on **frontend architecture, full-stack product delivery, workflow automation, and AI product engineering**.

I currently lead frontend development across **four Vue 3 web applications and one React Native mobile application**. I also build Python microservices, APIs, asynchronous workflows, and system integrations for production environments.

My experience spans legal and financial operations, energy, logistics, and real estate. I enjoy turning complex business workflows into maintainable products with clear architecture, dependable data flows, and thoughtful user experiences.

- Designed and implemented an **AI-powered legal and financial report-generation solution** spanning nine repositories, with validated structured output, asynchronous processing, failure recovery, and DOCX, PPTX, and PDF rendering.
